# Theory Lab 🎹🔬

> An interactive visual music theory sandbox for exploring scales, modes, chords, and keyboard harmony.

## ✨ Features
- **Interactive Piano Keyboard**: Real-time visual feedback for scales, modes, and chord voicings.
- **Harmonic & Modal Exploration**: Deep dive into scale degrees, modal interchange, and chord progressions.
- **Pure Web App**: Zero dependencies, 100% client-side HTML, CSS, and JavaScript.

## 🚀 Usage
Open `index.html` in any modern web browser.
